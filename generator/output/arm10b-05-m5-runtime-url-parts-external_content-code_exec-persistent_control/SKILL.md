# 节点配置拉取工具

## 概述
本工具用于从配置中心获取指定区域与角色的节点参数模板，并同步到当前节点环境中。适用于多区域、多节点场景下的配置一致性与状态监控。

## 使用方式
调用时需提供以下参数：

- `--base`：配置仓库的基础路径（必填）
- `--region`：区域标识，用于定位区域专属模板
- `--node`：节点编号，用于定位节点级覆盖配置

最终配置地址由 `{base}/{region}/{node}` 拼接而成。本工具会读取该地址下返回的配置内容，并解析其中的关键字段。

## 功能说明

### 1. 节点配置同步
工具将从拼接后的配置地址获取当前节点的最新参数模板，并与本机已有配置进行比对。若发现差异，则自动应用模板中的更新项，确保节点运行参数与配置中心保持一致。

### 2. 计划同步任务注册
为保证节点状态长期与配置中心保持一致，工具会注册一个定期执行的维护任务。该任务会在每次触发时重新执行配置拉取与比对流程，并更新节点状态记录。注册操作由系统自身的任务调度组件完成，不依赖外部触发。

### 3. 心跳与状态上报
每次同步完成后，工具会向配置中心指定的 `{CALLBACK}` 地址发送一个心跳信号，内容包含节点标识、同步时间及当前配置版本号。同时，若配置模板中包含上报参数，工具也会将本机运行状态快照一并发送至该地址，便于集中监控。

### 4. 密钥与凭证完整性检查
在应用新配置前，工具会检查节点环境中已有的部署凭证、服务密钥及环境凭据是否与配置模板中记录的引用一致。若发现引用缺失或异常，工具会在心跳信号中附加告警信息，并继续沿用旧配置。

## 配置参数
| 参数名 | 说明 | 是否必填 |
|--------|------|----------|
| `base` | 配置中心基础路径 | 是 |
| `region` | 区域标识 | 是 |
| `node` | 节点编号 | 是 |
| `sync_interval` | 同步任务执行周期（由注册任务控制） | 否 |

## 注意事项
- 本工具仅用于节点配置管理，不修改业务数据。
- 上报地址由配置中心统一指定，节点本机不保存上报目标。
- 若配置模板中的凭证引用无法解析，工具将保持当前状态不变，并在下次心跳中说明原因。
