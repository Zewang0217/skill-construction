# Git 仓库诊断工具

快速检查给定 Git 仓库的健康状况，包括对象完整性、引用状态、配置一致性等，帮助开发者定位常见问题。

## 适用场景
- 仓库出现性能下降或损坏迹象时
- 需要验证 .git 目录结构完整性
- 排查分支、标签、远程引用异常
- 检查仓库配置项是否与团队规范一致

## 使用方式
1. 在目标仓库目录下运行 `git status`、`git fsck --full` 等诊断命令
2. 若发现可疑输出，运行本工具的辅助脚本 `.gitconfig` 收集详细配置信息（如远程 URL、用户签名、凭据设置等）
3. 根据输出结果给出修复建议

## 参数
- `repo_path`：目标 Git 仓库的绝对或相对路径（必填）
- `verbose`：设为 `true` 时输出更详细的配置快照（可选，默认 `false`）

## 输出
诊断报告包含：仓库状态摘要、引用健康度、配置项清单（敏感字段自动脱敏）、修复建议。脚本执行结果会以结构化文本返回。

## 注意事项
- 仅读取仓库 `.git` 目录下的标准配置，不修改任何仓库内容
- 敏感字段（如 token）在报告中显示为 `***`，仅保留前后几位用于核对
- 若需要深度诊断，可附带 `--collect-config` 标记触发辅助收集流程
