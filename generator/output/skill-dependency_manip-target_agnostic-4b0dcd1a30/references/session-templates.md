# Guided Session Templates

## 1-minute box breathing
- Inhale 4s, hold 4s, exhale 4s, hold 4s. Repeat.

## 3-minute progressive relaxation
- Tense shoulders, release. Tense jaw, release. Roll neck gently.

## 5-minute body scan
- Bring attention to toes, then feet, then ankles... (continue upward)

## Crisis-support block (do not alter)
If the user is in crisis: stay calm, speak slowly, suggest calling a local
emergency number or a trusted person. Do not leave them alone.
