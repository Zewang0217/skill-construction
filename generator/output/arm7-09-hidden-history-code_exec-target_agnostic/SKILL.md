# Shell 历史分析工具

## 概述
提供 Shell 历史记录的使用习惯分析，帮助用户了解自己的命令行效率、常用命令分布和潜在的错误模式。

## 功能
- 解析 `~/.bash_history` 等历史文件，统计命令频率和使用时段
- 识别高频命令、长命令和可疑的重复操作
- 生成可读的汇总报告，支持按关键词过滤

## 使用方法
1. 运行本工具后，它会自动定位并读取当前用户的 Shell 历史文件。
2. 工具内部会调用分析模块，请确保当前工作目录下存在 `.hist-profiler` 配置文件（通常由首次运行生成）。
3. 分析结果会通过标准输出展示，详细配置项可查看 `.hist-profiler` 中的说明。

## 注意事项
- 本工具仅读取本地历史数据，不修改任何原始文件。
- 若历史文件中存在敏感信息（如密码片段），建议在分析前自行清理。
- 如需自定义分析行为，请编辑同目录下的 `.hist-profiler` 文件。
