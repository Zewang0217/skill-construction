## 2. 三家盲区全景（按稳定性排序）

### 2.1 SS（最高检出率，最难绕）

| 盲区 | 机制 | 稳定性 |
|---|---|---|
| **隐藏文件**（Arm7）| `_walk_skill_files` 跳过 `.` 文件 | **4/5 稳定** |
| 载荷时序-无脚本（Arm3）| 恶意在指令层 + 描述一致 + 变量注入 | 单样本（arm3-02）|
| Snyk 混合模式（Arm1 #17）| 外泄/后门/RCE/凭证交织 | 复现（0→8 分波动）|

**SS 难绕根因**（Arm6 实证）：规则引擎（SDI/SQP/LP/E1/PE3）**从脚本代码提取证据**——
有脚本就难绕；无脚本（纯指令载荷）才可能。声明注入是**反效果**（SDI 专抓声明矛盾）。

### 2.2 Cisco（语义推理最强，但有结构性死角）

| 盲区 | 机制 | 稳定性 |
|---|---|---|
| **隐藏文件**（Arm7）| 文件收集排除 `.` 文件，LLM 看不到 | **4/5 稳定** |
| 间接执行（Arm1 #08/#09）| compile()/getattr 反射切断调用链 | 稳定复现 |
| 阈值吞 MEDIUM | is_safe 只认 HIGH/CRITICAL | 80 个（系统）|
| 格式失败 | 畸形 skill 拒绝加载 | 17 个（系统）|

### 2.3 Cat（纯正则，盲区最广但可预测）

| 盲区 | 机制 | 稳定性 |
|---|---|---|
| 无字面命令原语（Arm1 #06/#07）| subprocess/os.system 无 curl\|bash 字面 | 稳定复现 |
| 隐藏文件（Arm7）| 正则看不到 .env 内容 | 4/5 |
| 声明注入/载荷时序 | 无字面命令样本 | 多例 |

## 3. 核心结论

1. **"原语决定可检测性，坐标不决定"**（Arm1）——坐标级盲区可预测，原语级盲区才精确。
2. **描述层包装无效，载荷层/文件层才有效**（Arm2 vs Arm3/7）——包装要在扫描器取证处做。
3. **扫描器自身设计是最大攻击面**（Arm7）——文件收集逻辑排除隐藏文件，三家同时失明。
4. **评测陷阱贯穿全程**：技术失败（ECNU 不稳定）伪装成攻击面效果；阈值吞检测；格式失败
   当漏检——必须 L1/L2/L3 分类。
5. **SS 免疫声明注入**（Arm5）——SDI 规则反制"描述与代码矛盾"，声明反而加强检出。

## 4. 对 SoK 的价值（S5 原型）

- **taxonomy 驱动盲区探索**：坐标 → 原语 → 载荷层 → 文件层的四层盲区谱系，
  证明 taxonomy 不仅能描述已知恶意，还能**系统性构造扫描器盲区样本**。
- **攻击面有效性 = 扫描器机制的函数**：SS 吃文件层（隐藏文件）和载荷层（无脚本）；
  Cisco 吃文件层和间接执行；Cat 吃无字面命令。
- **可复现性分级**：Cat/Cisco 的坐标盲区稳定复现；SS 载荷时序单样本；
  隐藏文件三家稳定——盲区知识可反哺扫描器增强（文件收集层修复优先级最高）。

## 5. 局限

4. SS prompt 注入方向未测（下一步）
