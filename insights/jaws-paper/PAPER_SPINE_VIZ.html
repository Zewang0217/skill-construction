Thesis

Automated security analyses routinely disagree, yet evaluations treat that disagreement as a statistic and stop — as if it were noise. Disagreement is not merely an evaluation statistic: projected into a shared observation space, its structure becomes falsifiable blind-spot predictions about the analyses themselves.

§1: “We argue that disagreement is not merely a statistic to report. It is analytical evidence: once disagreements are made comparable, their structure exposes what each analysis covers, what it cannot see, and why.” · 来源 main.tex §1 / main.pdf p1

三层分解示意

Three-Layer Decomposition + Hidden-File Case 每层：定义 · 修复 · 攻击策略 · 实证
L1 · COVERAGE

输入从未被收集

“The relevant input was never collected” —— 架构性盲区：scanner 根本不检查该区域。

Fix收集更多输入（含 hidden files）
Attack把 payload 放进被跳过的文件
Hypo隐藏文件 payload 逃逸（↓ 源码证据）
实证：SkillSpector build_context() 跳过 dotfiles → Arm7 中 14/15 逃逸（11 个 score=0），raw output 只记录 ['SKILL.md']。§5 surface：Cisco 深伪装 RCE 14%、SS 内容操纵/反弹 shell 0%。
L2 · DETECTION

引擎无法识别该行为

“The input was collected but the engine cannot recognize the behavior” —— 表面不匹配：词汇/语义表面消失即漏。

Fix换引擎 / 增强识别能力
Attack改变表达（去字面、换语义）
Hypono-literal / finding-family 变体（↑ 矩阵证据）
实证：Caterpillar 只匹配词汇标记 → H2 无字面措辞 10/10 逃逸、隐藏文件样例 13/15 零发现；Cisco 字面触发（窄）→ H3 finding-family 变体 6/6 逃逸。
L3 · DECISION

发现被阈值丢弃

“The engine produced a finding but the decision rule discarded it” —— 引擎看到了，规则把结果压掉。

Fix改阈值 / 报告规则
Attack压低严重度（保持 MEDIUM 以下）
Hypoconjunction 欠评分（↓ 源码证据）
实证：Cisco is_safe 只保留 CRITICAL/HIGH → MEDIUM 被吞：隐藏文件样例 11/15 逃逸、H4 叠加弱机制 5/5（SS≤50）、灰区 662/3,996 benign 的 MEDIUM 不可见、88/581 恶意 is_safe。

机制备注（§7 The Ledger）

H3 机制：每个 SkillSpector finding family 一个变体，重表达同一恶意行为；Cisco 静态层无东西可供 severity 逻辑升级 → 六个全部 is_safe（INFO–MEDIUM），而 SkillSpector 六个全给分：同一坐标、两个 scanner、不同层。
H2 机制：exfiltration 用工具语义表达（“archive the result to the remote repository”），全文无 curl/base64 token；regex 引擎无物可匹配。
H4 机制：叠加隐藏放置 + 间接执行 + 声明能力掩护，每个都低于评分阈值；additive scorer 永远看不到合取 → 2/5 同时逃逸全部三个 scanner。
